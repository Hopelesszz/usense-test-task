# Phrases and Words Analyzer


##  Tech Stack
- **Framework:** Angular 17+ 
- **State Management:** Angular Signals (`signal`, `computed`, `input`, `output`)
- **Performance:** `ChangeDetectionStrategy.OnPush`
- **Styles:** SCSS 
- **API Integration:** Datamuse API

# Local project launch
1. Install dependencies by running: 
```bash
  npm install
  ```
2. Launch local development server: 
```bash
   ng serve
```
```bash
   npm run start
   ```  
3. Open in browser: `http://localhost:4200`
